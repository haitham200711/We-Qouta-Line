# نظام متابعة واستعلام جيجات خطوط وي الأرضي (WE Quota Monitor)

لوحة تحكم ذكية وشاملة لمتابعة باقات الإنترنت المنزلي (ADSL / VDSL / FTTH) لشركة المصرية للاتصالات (WE / Telecom Egypt) لعدة خطوط معاً في صفحة واحدة، مع إرسال تنبيهات تلقائية عبر تيليجرام (Telegram Bot).

---

## 🌟 المميزات الرئيسية
1. **متابعة خطوط متعددة:** إضافة وإدارة أي عدد من الخطوط الأرضية لحسابات مختلفة في واجهة واحدة موحدة وسريعة.
2. **استعلام مباشر ولحظي:** الاتصال الفوري ببوابة خدمات وي الرسمية وجلب الباقة الكلية، الجيجات المستهلكة، الجيجات المتبقية، ونسبة الاستهلاك.
3. **مواعيد التجديد بدقة:** حساب الأيام المتبقية حتى تاريخ تجديد الباقة بدقة متناهية.
4. **تحديث تلقائي في الخلفية:** فحص وتحديث دوري للخطوط (كل ساعة، ساعتين، 4 ساعات، أو 6 ساعات) بدون الحاجة لفتح المتصفح.
5. **تنبيهات تيليجرام الذكية:** إرسال رسائل فورية وتنبيهات عند:
   - انخفاض الرصيد المتبقي عن حد الخطر (مثلاً أقل من 20% أو أقل من 15 جيجا).
   - اقتراب موعد تجديد الاشتراك (قبل 3 أيام مثلاً).
   - منع الإزعاج: خاصية Cooldown ذكية تمنع تكرار نفس التنبيه إلا بعد مرور 18 ساعة.
6. **واجهة عربية عصرية وسريعة (RTL):** تصميم مريح وأنيق مبني بأحدث تقنيات الويب، يدعم الوضع المظلم والأجهزة المختلفة (شاشات الكمبيوتر والموبايل).

---

## 🚀 طريقة التشغيل السريعة

### التشغيل العادي (مع إمكانية متابعة السجلات):
- اضغط مرتين (Double Click) على الملف:
  ```
  RUN.bat
  ```
  سيقوم السكربت بتشغيل السيرفر تلقائياً وفتح لوحة التحكم في متصفحك على:
  `http://localhost:8000`

### التشغيل الصامت في الخلفية (Silent / Background):
- اضغط مرتين على الملف:
  ```
  START_BACKGROUND.vbs
  ```
  سيعمل السيرفر بالخلفية بدون إظهار أي نافذة أو شاشة سوداء.

## 📱 إعداد تنبيهات تيليجرام (Telegram Alerts)

1. أنشئ بوت تيليجرام عبر التحدث مع [@BotFather](https://t.me/BotFather) بالضغط على `/newbot`، وانسخ رمز الـ **Bot Token**.
2. للحصول على الـ **Chat ID** الخاص بك، يمكنك مراسلة [@userinfobot](https://t.me/userinfobot) أو إضافة البوت إلى مجموعة وأخذ الـ Chat ID.
3. افتح لوحة التحكم `http://localhost:8000`، واضغط على **"إعدادات التنبيهات"**.
4. ضع الـ Token والـ Chat ID، واضغط **"إرسال رسالة تجريبية"** للتأكد من نجاح التوصيل ثم اضغط **"حفظ الإعدادات"**.

---

## 🗂️ هيكل الملفات
- `app.py`: السيرفر الرئيسي (FastAPI) ونقاط الاتصال API.
- `we_api.py`: كلاس الربط التلقائي والتعامل مع بوابات شركة وي والحسابات.
- `telegram_notifier.py`: نظام إرسال الرسائل والتنبيهات المنسقة عبر تيليجرام.
- `scheduler.py`: المجدول التلقائي لتحديث الجيجات وإطلاق التنبيهات دورياً.
- `storage.py`: حفظ واسترجاع بيانات الخطوط والإعدادات بأمان في ملفات JSON.
- `templates/index.html`: واجهة المستخدم التفاعلية المتجاوبة.
- `data/`: مجلد يتم إنشاؤه تلقائياً لحفظ الخطوط والإعدادات محلياً على جهازك.
